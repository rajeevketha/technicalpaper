# Polish checklist

- [ ] Title specific and honest
- [ ] Abstract standalone and quantitative where possible
- [ ] Contribution bullets match body and experiments
- [ ] Terms defined before use
- [ ] Notation consistent
- [ ] Figures referenced in text before/at first mention
- [ ] No identity leaks if double-blind
- [ ] Self-citations anonymized appropriately
- [ ] Within page limit including references/appendix rules
- [ ] Spellings of method/system names consistent
- [ ] Limitations section present and non-defensive
- [ ] Broader impact / ethics statement if required
