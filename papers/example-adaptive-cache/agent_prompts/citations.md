# Agent prompt — citations

Harden bibliography and claim support.

## Do this

1. Scan the manuscript for strong claims lacking citations.
2. Clean `references.bib` formatting and keys.
3. Remove or flag unverifiable entries.
4. Ensure related-work coverage of closest alternatives.
5. Produce a short list of missing citations the author should add.

## Guardrails

- Never invent bibliographic metadata.
- Prefer asking for a DOI/title over guessing.
