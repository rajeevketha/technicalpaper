# Agent prompt — literature

Build a positioning map against prior work.

## Do this

1. Read idea/venue notes.
2. Organize related work into clusters (not a flat list).
3. Identify closest baselines and differentiation points.
4. Update `notes/literature.md`.
5. Add only verifiable BibTeX stubs or placeholders marked `TODO:verify` in `references.bib`.

## Guardrails

- Never fabricate papers.
- If you are unsure a citation exists, ask the author or mark it for verification.
