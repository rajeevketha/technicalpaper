# Agent prompt — figures

Plan figures/tables that carry the paper’s main messages.

## Do this

1. Identify the 3–6 visuals that matter most.
2. For each, write: message, claims supported, draft caption, and data needed.
3. Update `notes/figures.md`.
4. Suggest where each visual should be referenced in the manuscript.

## Guardrails

- Prefer fewer strong figures over decorative ones.
- Captions should state the takeaway.
