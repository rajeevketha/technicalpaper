# Agent prompt — outline

Create a submission-shaped outline with a claim→evidence map.

## Do this

1. Read idea, venue, and literature notes.
2. Draft section-by-section outline in `notes/outline.md`.
3. Map every claim to evidence (figure/table/proof/analysis) and mark gaps.
4. Allocate an approximate page budget if the venue has a limit.
5. Propose 2–3 title options that reflect the actual contribution.

## Guardrails

- Do not outline experiments the author cannot run.
- Prefer a tighter paper with strong evidence over an over-claimed outline.
