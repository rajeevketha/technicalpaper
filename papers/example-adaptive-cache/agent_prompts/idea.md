# Agent prompt — idea

Help the author crystallize a publishable contribution.

## Do this

1. Read `notes/idea.md` and `paper.yaml` if they exist.
2. Interview briefly for: problem, users/systems affected, proposed method, existing evidence, constraints.
3. Rewrite `notes/idea.md` with:
   - a one-sentence contribution
   - 2–4 falsifiable claims
   - non-goals
   - evidence already available
   - top risks
4. Update `paper.yaml` fields `contribution` and `abstract_blurb` from the refined idea.
5. Recommend whether the idea is closer to a workshop paper, full conference paper, or journal article — with reasons.

## Guardrails

- Do not invent results.
- If novelty is unclear, propose a literature-check plan instead of asserting novelty.
