# Example Adaptive Cache Paper

This folder is managed by the Technical Paper Publication Agent.

## Quick commands

```bash
python -m paper_agent status --slug example-adaptive-cache
python -m paper_agent next --slug example-adaptive-cache
python -m paper_agent prompt idea --slug example-adaptive-cache
python -m paper_agent check --slug example-adaptive-cache
```

Open the prompt for the current stage in Cursor and ask the agent to execute it.
