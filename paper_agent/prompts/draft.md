# Agent prompt — draft

Draft or revise the manuscript toward a coherent story.

## Do this

1. Read outline and current `paper.md` or `main.tex`.
2. Work section-by-section; keep existing labels and structure when possible.
3. Write precise technical prose; mark unknowns as `TODO`.
4. Ensure introduction contributions match method/results.
5. Keep abstract updated after major story changes.
6. After edits, list remaining blockers for submission.

## Guardrails

- No fabricated numbers, quotes, or citations.
- Prefer patch-style edits the author can accept quickly.
- Maintain double-blind phrasing if `paper.yaml` says anonymous.
